# Тренировки и товарищеские матчи

Кроме турниров, сервер с плагином ArenaPro подходит для тренировок: раскидка гранат, отработка позиций с ботами, а также для товарищеских матчей (скримов) без турнира и без панели. Все команды пишутся в чат игры. Вместо точки можно ставить `!`: `.prac` и `!prac` работают одинаково. Команда `.help` выводит список доступных команд прямо в игре.

## 1. Запустить сервер для тренировки

1. В панели откройте **Серверы** и нажмите **Запустить** у нужного сервера.
2. В **Настройках** сервера выберите **Режим**: *competitive* для 5v5 и карт соревновательного режима или *wingman* для 1v1 и 2v2 на картах «Напарников». Режим применяется при следующем запуске сервера.
3. Карту можно сменить сразу кнопкой **Сменить карту сейчас** или командой `.map de_mirage` в игре (нужны права админа, см. ниже).
4. Подключитесь из игры: консоль (`~`) → `connect <адрес>:<порт>`. Адрес и порт показаны в списке серверов. Если в настройках задан **Пароль для входа**, сначала введите `password <пароль>`, потом `connect`.

Сервер, который вы запустили вручную, панель не отдаёт под турнирные матчи, поэтому игроков на нём не выкинет. **Внешний сервер** (запущен не из панели) панель считает свободным и может отправить на него турнирный матч. Пока на нём тренируются, выключите у турнира автозапуск матчей или используйте другой сервер.

После тренировки остановите сервер кнопкой **Остановить**.

## 2. Кто может включать тренировку

Включать тренировку и пользоваться командами админа (`.prac`, `.map`, `.start` и т. д.) могут только админы ArenaPro.

- **Админы из панели.** Войдите в панель полным админом (логином и паролем или через Steam) и откройте раздел **Админы**. Введите SteamID64 игрока или выберите из списка игроков, которые уже входили в панель через Steam, и выберите права на сервере:
  - **Админ** — все команды ArenaPro;
  - **Только тренировки и смена карты** — `.prac`, `.exitprac` и `.map`.

  В столбце **Панель** выбираются права в самой панели при входе через Steam:
  - **Нет** — обычный игрок;
  - **Админ панели** — турниры, серверы, карты и матчи; раздел «Админы» он только видит;
  - **Полный админ** — может всё, в том числе выдавать и снимать права админов; на сервере у него всегда права «Админ».

  Логин и пароль учётной записи администратора через Steam не меняются.

  Панель записывает список в `cfg\ArenaPro\admins.json` в папке CS2 (в установке скриптом это `D:\cs2-server\cs2\game\csgo\cfg\ArenaPro\admins.json`) и сразу применяет его на работающих серверах. Выключенные серверы прочитают его при запуске. Админы, которые раньше были вписаны в этот файл вручную, при первом открытии раздела переносятся в панель. Внешний сервер в другой папке или на другом компьютере панель не обновляет: там файл нужно править вручную и писать в игре `.reload_admins`.

- **Код админа.** Права админа на сервере сами по себе не включаются: сначала админ вводит код в консоли игры (`~`), не в чате:

  ```
  arenapro_auth КОД
  ```

  Во время турнирного матча нужен код этого матча: его видят только админы панели в комнате матча, в блоке «Управление матчем». На сервере без матча (тренировка) действует общий код из раздела **Админы** панели, там же его можно сменить. Вход действует, пока игрок на сервере; после переподключения или смены кода его нужно ввести снова. После 5 неверных попыток ввод блокируется на 5 минут.

- **Все игроки — админы.** На отдельном тренировочном сервере можно дать права всем: в настройках сервера в поле **Дополнительные команды cfg** добавьте строку `arenapro_everyone_is_admin true`. Это даёт каждому игроку и доступ к консоли сервера через `.rcon`, поэтому включайте это только на сервере с паролем для входа и никогда на турнирном.

## 3. Режим тренировки

Включается командой `.prac` (или `.tactics`), если на сервере не идёт матч. Выход: `.exitprac`, сервер вернётся в обычный режим матча.

### Гранаты

| Команда | Что делает |
|---|---|
| `.rethrow` (`.rt`) | Повторить последнюю брошенную гранату |
| `.rethrowsmoke`, `.rethrowflash`, `.rethrownade`, `.rethrowmolotov`, `.rethrowdecoy` | Повторить последнюю гранату этого типа |
| `.last` | Вернуться на место, откуда бросили последнюю гранату |
| `.back <номер>` | Вернуться к позиции из истории бросков |
| `.throwindex 1 2 …` | Бросить гранаты из истории по номерам (можно несколько сразу) |
| `.lastindex` | Номер последней гранаты в истории |
| `.delay <секунды>` | Задержка для последней гранаты при `.rethrow` и `.throwindex` |
| `.savenade <имя> [описание]` (`.sn`) | Сохранить раскидку |
| `.loadnade <имя>` | Встать на сохранённую раскидку |
| `.listnades [фильтр]` (`.lin`) | Список сохранённых раскидок |
| `.deletenade <имя>` (`.dn`) | Удалить раскидку |
| `.importnade <код>` (`.in`) | Добавить раскидку по коду, который выводится в чат при сохранении |
| `.clear` | Убрать все дымы и молотовы |
| `.fastforward` (`.ff`) | Промотать время на 20 секунд (дым рассеется быстрее) |
| `.noflash` (`.noblind`) | Не слепнуть от своих флешек |
| `.traj` | Показывать траекторию гранаты |
| `.impacts` | Показывать места попаданий пуль |

Сохранённые раскидки хранятся в `cfg\ArenaPro\savednades.json` и не пропадают при обновлении.

### Боты и позиции

| Команда | Что делает |
|---|---|
| `.bot` | Поставить бота на вашем месте |
| `.crouchbot` (`.cbot`) | Поставить присевшего бота |
| `.boost` / `.crouchboost` | Поставить бота и встать ему на голову |
| `.nobots` | Убрать всех ботов |
| `.spawn <номер>` | Встать на соревновательный спавн своей стороны |
| `.ctspawn <номер>` (`.cts`), `.tspawn <номер>` (`.ts`) | Встать на спавн CT или T |
| `.bestspawn` / `.worstspawn` | Ближайший или самый дальний спавн своей стороны |
| `.showspawns` / `.hidespawns` | Показать или скрыть все спавны |

### Прочее

| Команда | Что делает |
|---|---|
| `.ct`, `.t`, `.spec` | Перейти за CT, T или в наблюдатели |
| `.fas` (`.watchme`) | Всех, кроме вас, перевести в наблюдатели (показать раскидку) |
| `.god` | Бессмертие |
| `.timer` | Секундомер: первый раз запускает, второй останавливает и пишет время |
| `.break` | Разбить всё разрушаемое на карте (стёкла, двери, вентиляции) |
| `.solid` | Включить или выключить столкновения с союзниками |
| `.dryrun` (`.dry`) | Прогон раунда с настоящей экономикой и временем закупки |

## 4. Товарищеский матч (скрим) без турнира

Для игры «на интерес» турнир в панели создавать не нужно. На запущенном сервере без матча:

1. Все заходят на сервер и расходятся по сторонам.
2. Админ задаёт названия команд: `.team1 Название` (по умолчанию CT) и `.team2 Название`.
3. Нужные настройки (только админ):
   - `.readyrequired <число>` — сколько игроков должны написать `.ready`, чтобы матч начался; `0` — все, кто на сервере. По умолчанию 2: для 5v5 поставьте `.readyrequired 10` или `0`.
   - `.roundknife` (`.rk`) — включить или выключить ножевой раунд.
   - `.playout` — играть все раунды, даже если победитель уже ясен (без овертаймов).
   - `.settings` — показать текущие настройки.
4. Игроки пишут `.ready` (отменить: `.unready`). Админ может начать без готовности: `.start`.
5. После ножевого раунда победитель пишет `.stay` (остаться) или `.switch` (поменять стороны).

Во время матча:

| Команда | Что делает |
|---|---|
| `.pause` / `.unpause` | Пауза в закупке; снять её должны обе команды |
| `.tech` | Техническая пауза |
| `.stop` | Откатить текущий раунд (должны написать обе команды) |
| `.restore <номер>` | Админ: восстановить начало раунда с этим номером |
| `.forcepause` / `.forceunpause` | Админ: поставить или снять паузу без согласия команд |
| `.restart` (`.rr`) | Админ: сбросить матч и начать заново |
| `.endmatch` | Админ: завершить матч без победителя |

Результаты такого матча в панель не попадают, и сервер после него не выключается.

## 5. Тренировка режима турнира

Чтобы целиком проверить турнирный сценарий (вето, подключение, `.ready` капитанов, кик после матча), создайте в панели тестовый турнир на 2 команды и пройдите его. Для теста можно сократить ожидание, запустив панель с переменными окружения:

```powershell
$env:JOIN_TIME_S = 120; $env:VETO_TURN_S = 15; .\start-panel.ps1
```

`JOIN_TIME_S` — время на подключение к серверу (по умолчанию 600 секунд), `VETO_TURN_S` — время на ход в вето (по умолчанию 30). Тестовый турнир потом можно удалить на его странице.
