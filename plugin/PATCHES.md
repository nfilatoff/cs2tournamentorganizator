# Наши правки поверх автоматического переименования

Эти изменения нужно вернуть после обновления плагина с оригинала (см. `tools/UPDATING.md`).

1. **`ArenaPro.csproj`**: версия `CounterStrikeSharp.API` поднята с 1.0.376 до 1.0.379 (должна совпадать с CounterStrikeSharp на серверах).
   Причина: версия 1.0.376 падала на CS2 1.41.9.4 при подключении игрока.
2. **`ConfigConvars.cs` и `cfg/ArenaPro/config.cfg`**: настройка `arenapro_show_credits_on_match_start` по умолчанию `false`
   (сообщение с авторством в игровом чате отключено).
3. **`NOTICE.md`** добавлен (авторство и ссылка на оригинал). Файл `LICENSE` не менялся.
